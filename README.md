# Appliance Energy Australia

A small interactive website created for the Data Visualisation unit.

The website provides placeholder information about appliance energy
consumption in the Australian market and demonstrates the use of HTML,
CSS and JavaScript.

## Website Pages

The website contains three pages:

- Home
- Televisions
- About Us

The navigation menu allows users to move between the pages, while the
power logo returns the user to the Home page.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Desktop

## Project Purpose

This project was created as part of a tutorial exercise to refresh
HTML, CSS and JavaScript skills and provide a foundation for future
data visualisation tasks.

The website will be updated during later tutorials to include data
visualisations and storytelling based on appliance energy consumption.

## GenAI Acknowledgement

GenAI tools were used to assist with the development of this website.

All generated code was reviewed and tested before being included in
the project.

## GitHub Copilot Reflection

GitHub Copilot was used as part of the development process to assist
with writing and understanding code.

Copilot was useful for suggesting code and providing ideas when
developing the website. However, the suggestions still needed to be
reviewed and tested to make sure they worked correctly and matched
the requirements of the task.

This experience showed that AI coding tools can speed up development,
but it is still important to understand the code being used rather
than relying on the suggestions without checking them.
